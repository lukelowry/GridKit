# Adaptive-step simulation benchmarks

Runs in this directory profile `DynamicSimulation` with IDA adaptive stepping.
Each dated directory is self-contained so later runs can use different cases,
instrumentation, compilers, or branches without overwriting earlier evidence.

- [`2026-07-27-texas-wecc/`](2026-07-27-texas-wecc/): restored Texas 2k and
  WECC baselines, output controls, and Texas BusFault sensitivity analysis.
