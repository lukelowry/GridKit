# Case sweep benchmarks

Runs in this directory time `DynamicSimulation` across the whole example case
set under one harmonized study, so cases can be compared against each other
rather than against their own historical settings. Each dated directory is
self-contained.

- [`2026-07-28-medium-large-huge/`](2026-07-28-medium-large-huge/): all six
  Medium, Large and Huge cases at two horizons, 20 s with the fault at 10.0 s
  and 10 s with the fault at 1.0 s. Monitor output disabled.
