# Convolution

This directory contains helper models for representing convolution
operators in phasor dynamics.

- [ConvolutionVF](ConvolutionVF/README.md): vector-fitting convolution helper.
- [ConvolutionVec](ConvolutionVec/README.md): vector-valued vector-fitting convolution helper.

## Examples

- `ConvolutionVecDemo`: three-phase matrix convolution driven by CSV-backed
  mock input history.
