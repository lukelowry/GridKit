# BranchFrequencyDependent Model

`BranchFrequencyDependent` represents the characteristic-admittance current
injection of a frequency-dependent transmission line. Version 1 consumes a
phase-domain `Yc(s)` rational fit from a `.fit.json` sidecar and applies the
same fitted admittance independently at the `from` and `to` ports.

This model is intentionally `Yc`-only. It does not yet implement distributed
propagation, travel time, or history terms. Case files must omit
`propagation`; that field is reserved for the next extension.

## Model Parameters

| Field | Units | Description |
| --- | --- | --- |
| `length` | m | Physical line length. It is retained with the component data and must be positive. |
| `phase_order` | none | Must be `["a", "b", "c"]` and must match the sidecar. |
| `yc.fit_file` | path | Path to the characteristic-admittance `.fit.json` sidecar. |
| `yc.sha256` | none | Optional SHA-256 hash of the sidecar bytes. |

The referenced sidecar must satisfy the EMT rational-fit schema documented in
[FIT_JSON.md](../../../IO/FIT_JSON.md).

## Case Example

```json
{
  "name": "line",
  "class": "BranchFrequencyDependent",
  "params": {
    "length": 150000.0,
    "phase_order": ["a", "b", "c"],
    "yc": {
      "fit_file": "fits/ol_345_horizontal_acsr_twin_transposed.yc.fit.json",
      "sha256": "b913334383f4cf4befeb0a060154813bc69ce75f8a997b2df366c0f8f161266c"
    }
  },
  "ports": {
    "from": "source_bus",
    "to": "receiving_bus"
  },
  "mon": ["ifa", "ifb", "ifc", "ita", "itb", "itc"]
}
```

Relative sidecar paths resolve against the case-file directory.

## Model Variables

The component owns two independent rational-approximation realizations, one for
each electrical port. The local state count is dynamic:

```text
state_count = 2 * Yc.state_count()
```

All local variables are differential state variables from the rational
realizations. If the fit is a pure feedthrough `D + sE` model with no poles,
the component has no local variables.

## Model Equations

At each port, the fitted admittance maps phase voltage and voltage derivative
to a port current:

```text
i_yc = Yc(v)
```

GridKit bus residuals use current injections positive into the bus, so the
component contributes:

```text
i_from_inj := -Yc(v_from)
i_to_inj   := -Yc(v_to)
```

The rational state residuals are generated by
`GridKit::EMT::Math::RationalApprox`.

## Initialization

The component initializes each rational realization from the connected bus
instantaneous voltages and voltage derivatives. The `from` and `to`
realizations are initialized independently.

## Model Outputs

Monitor variables expose the current injections that the branch contributes to
each port bus:

| Monitor | Description |
| --- | --- |
| `ifa`, `ifb`, `ifc` | `from` port phase current injections. |
| `ita`, `itb`, `itc` | `to` port phase current injections. |
